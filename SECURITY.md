# Security policy

## Reporting a vulnerability

Please email [ducttapeworks@proton.me](mailto:ducttapeworks@proton.me) rather than opening a public issue. Include what you found, how to reproduce it, and the Polyscope version (**Settings → Help → Copy diagnostics** has it).

We'll acknowledge your report as soon as we can, and let you know when a fix is released. Polyscope is maintained in spare time, so please allow a reasonable period before disclosing publicly.

## Supported versions

Only the [latest release](https://github.com/ducttapeworksorg/polyscope/releases/latest) gets security fixes. Polyscope updates itself, so keeping it running is usually enough to stay current.
